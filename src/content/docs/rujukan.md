---
title: Referensi
description: Bacaan lanjutan dan sumber konsep yang diadaptasi untuk modul.
---

Materi dalam modul ini ditulis dengan contoh dan dataset latihan sendiri. Rujukan berikut membantu memperdalam topik atau membandingkan cara penyajiannya.

- **Python dasar dan notebook:** [Python Tutorial resmi](https://docs.python.org/3/tutorial/) membantu menelusuri sintaks, alur kontrol, fungsi, struktur data, modul, dan penanganan galat. Tutorial tersebut mengasumsikan pembaca sudah memahami dasar pemrograman; materi di sini menguraikan langkah pemulanya terlebih dahulu. [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/) oleh Jake VanderPlas menjadi bacaan lanjutan untuk IPython, NumPy, pandas, dan visualisasi.
- **Visualisasi dengan Matplotlib:** [Pyplot tutorial](https://matplotlib.org/stable/tutorials/pyplot.html), [Figure](https://matplotlib.org/stable/users/explain/figure/figure_intro.html), [Axes](https://matplotlib.org/stable/users/explain/axes/axes_intro.html), [galeri histogram](https://matplotlib.org/stable/gallery/statistics/hist.html), [galeri boxplot](https://matplotlib.org/stable/gallery/statistics/boxplot_demo.html), dan [referensi diagram lingkaran](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.pie.html). Modul memakai contoh dasar secara langsung dan mempertahankan konteks serta data latihan sendiri.
- **Eksplorasi data dan statistika komputasional:** Allen B. Downey, [Think Stats](https://greenteapress.com/thinkstats2/thinkstats2.pdf) , edisi kedua, terutama eksplorasi, distribusi, peluang, dan simulasi.
- **Deskriptif, sampling, dan pengujian:** Peter Bruce dan Andrew Bruce, *Practical Statistics for Data Scientists*, edisi pertama; Peter Bruce, Andrew Bruce, dan Peter Gedeck, edisi kedua, terutama bab 1-3. [Repositori kode edisi kedua](https://github.com/gedeck/practical-statistics-for-data-scientists) menyediakan contoh untuk pembaca yang sudah lebih siap.
- **Contoh analisis Python lanjutan:** [AI-Assisted Statistics for Data Scientists, kode Python bab 1](https://gedeck.github.io/ai-assisted-statistics-for-data-scientists/docs/python/ch01.html).
- **Urutan konsep pengantar berbahasa Indonesia:** [Pengantar Statistik untuk Sains Data](https://bookdown.org/dsciencelabs/statistika_dasar/_book/index.html), bagian konsep data, pengumpulan, penyajian, pemusatan, penyebaran, dan probabilitas.
- **Acuan pustaka kode:** [dokumentasi pandas](https://pandas.pydata.org/docs/), [dokumentasi Matplotlib](https://matplotlib.org/stable/users/index.html), dan [dokumentasi Python `statistics`](https://docs.python.org/3/library/statistics.html).
