## Soal 1 — baca ekspresi

Tanpa menjalankan, tebak keluaran. Mengapa hasil kedua bernilai `True`?

```python
jarak_meter = 450
waktu_menit = 12
print(jarak_meter / 1000)
print(waktu_menit >= 10)
```

<details>
<summary>Pembahasan</summary>
<p>Keluaran `0.45` lalu `True`. Pembagian mengubah meter menjadi kilometer; perbandingan `&gt;=` menghasilkan nilai boolean. Satuan hasil pertama adalah kilometer.</p>
</details>

## Soal 2 — lengkapi aturan

Jalankan kode, lalu ganti `>` dengan `>=`. Apa yang berubah untuk nilai tepat 15?

```python
waktu_menit = [12, 15, 18]
for menit in waktu_menit:
    if menit > 15:
        print(menit, "melewati batas")
```

<details>
<summary>Pembahasan</summary>
<p>Dengan `&gt;`, hanya 18 melewati batas. Dengan `&gt;=`, 15 dan 18 ikut tercetak. Simbol batas merupakan bagian dari definisi kategori, bukan hiasan sintaks.</p>
</details>

Pada kode berikut, ubah `ambang` menjadi 15 lalu 20. Cetak nilai waktu yang lolos dan jumlahnya. Perhatikan bahwa list dipakai berulang, sedangkan tuple, set, dan dictionary mengerjakan tugas yang berbeda.

### Cara membaca kode

| Bagian | Yang dilakukan |
|---|---|
| `waktu_menit = [...]` | Menyimpan enam pengamatan berurutan di dalam list. |
| `ambang = 15` | Memberi nama pada batas yang akan diuji. |
| `jumlah = 0` | Menyiapkan penghitung sebelum perulangan dimulai. |
| `terpilih = []` | Menyiapkan list kosong untuk menyimpan nilai yang lolos. |
| `for menit in waktu_menit:` | Mengambil satu nilai pada setiap putaran. |
| `if menit > ambang:` | Memeriksa syarat untuk nilai yang sedang diproses. |
| `.append(menit)` | Menambahkan nilai yang lolos ke akhir list. |
| `jumlah += 1` | Menambah penghitung satu setiap kali syarat benar. |
| `set(waktu_menit)` | Mengambil nilai berbeda saja; ini membuang informasi banyaknya pengulangan. |
| `zona = {...}` | Dictionary memasangkan nama kunci dengan nilai. |

Keluaran awal: nilai terpilih `[18, 30]`, jumlah `2`, dan nilai unik `[8, 12, 15, 18, 30]`. Nilai 12 muncul dua kali pada list tetapi hanya sekali pada set. Bila ambang diubah menjadi 20, nilai terpilih menjadi `[30]` dan jumlahnya 1.

## Soal 4 — tulis fungsi ringkas

Tambahkan fungsi yang menerima list waktu dan mengembalikan median. Gunakan `statistics.median` agar perhatian tertuju pada masukan, pemanggilan fungsi, dan hasilnya.

```python
from statistics import median

def nilai_tengah(nilai):
    return median(nilai)

print(nilai_tengah([8, 12, 18]))
```

Keluaran: `12`. `return` mengirim hasil dari fungsi; `print` menampilkannya.

## Kesimpulan

Python menjalankan instruksi berurutan. Variabel menyimpan nilai, kondisi memilih tindakan, perulangan memproses banyak nilai, dan fungsi memberi nama pada langkah yang dapat dipakai ulang. List mempertahankan urutan dan duplikasi; tuple menyimpan urutan tetap; set menyimpan anggota unik; dictionary memasangkan kunci dengan nilai. Dalam analisis data, pahami dulu apa yang dihitung sebelum mempercayai keluaran kode.

Jika kode gagal, baca pesan galat, cocokkan nama dan tipe, periksa indentasi, lalu jalankan kembali seluruh sel yang diperlukan.
